# 磐卷 · 安装说明（给不太懂电脑的家长）

**你要做的事：解压 → 双击一个文件 → 浏览器自动打开 → 把老师发的作业拖进去。**
全程在你自己电脑上完成，不联网上传任何东西，孩子的作业不会离开你的电脑。

---

## 第一步：确认电脑上有 Python（只需做一次）

Python 是一个免费的小工具，很多软件都靠它跑。

1. 按键盘上的 **Win + R**，弹出小窗口
2. 输入 `py -3.11 --version` 后回车
3. 看到 `Python 3.11.xx` 之类的字 → **你有，直接跳到第二步**
4. 如果提示"找不到"或窗口一闪而过 → 你需要装一个：
   - 打开 https://www.python.org/downloads/
   - 点黄色大按钮 Download 下载
   - **安装第一个界面，务必勾选最下面的 `Add python.exe to PATH`**（不勾后面会很麻烦）
   - 一路"下一步"装完即可

> 装 Python 是这类开源工具唯一的门槛。装一次，以后所有同类工具都能用。

---

## 第二步：运行安装脚本

1. 把 `paper-forge-v1.0.zip` **解压到一个文件夹**（右键 → 全部提取）
   ⚠️ 一定要解压，不要在压缩包里直接双击运行
2. 打开解压出来的文件夹，进入 `scripts` 文件夹
3. 找到 `setup.ps1`，**鼠标右键点它 → 选"使用 PowerShell 运行"**
4. 会弹出一个蓝色/黑色的窗口，开始自动装东西，**耐心等 1–3 分钟别关窗口**
   - 中间会滚很多字，是正常的
   - 看到 `磐卷已就绪 → http://127.0.0.1:8000/` 就说明成功了
   - 浏览器会自动打开页面

> 如果右键没有"使用 PowerShell 运行"这个选项：
> 在那个文件夹的地址栏输入 `powershell` 回车，在弹出的窗口里输入
> `.\setup.ps1` 回车即可。

---

## 第三步：出卷子

1. 浏览器打开后，会看到"把老师发的作业拖进来"的大框
2. 把手机里的作业文件**拖进去**（或点"或点击选择"挑文件）
   - 支持：PDF、照片（jpg/png）、Word 文档（.docx）
   - 可以一次拖好几个，**你放的顺序就是卷子的页序**
   - 拖错了可以用列表里的 ↑ ↓ 调整顺序，✗ 删除
3. 点**"开始出卷"**
4. 几秒后自动跳到预览页，左边是每页缩略图，中间是大图，右边是选项：
   - **字号**：孩子眼睛吃力就调大
   - **2 合 1**：两页印在一张纸上，省纸
   - **显示班级/姓名栏**：不想填就关掉
   - 改完点**"应用并重排"**，几秒刷新
5. 点**"下载试卷 PDF"** → 打开就是标准 A4，直接打印

---

## 以后怎么用

每次用只需要：**双击 `setup.ps1`**（它检测到东西装好了会直接启动，几秒钟），
或者在解压文件夹的地址栏输 `powershell` 回车，再输
`.\.venv\Scripts\python -m uvicorn app.main:app --port 8000` 回车。

浏览器地址是 `http://127.0.0.1:8000/`，书签存一下更方便。

## 常见问题

**问：拖进去的文件里老师给的 .doc（老版 Word）打不开？**
答：用 Word 打开它，"另存为"选 `.docx`，再拖进来。老格式技术上不支持，不是漏了。

**问：蓝色窗口一闪就没了？**
答：多半是第一步的 Python 没装好或没勾 Add to PATH。重做第一步。

**问：提示"不支持的格式"？**
答：目前支持 PDF / jpg / jpeg / png / webp / bmp / docx。微信里收到的文件有时没有扩展名，重命名加上 `.jpg` 或 `.pdf` 再拖。

**问：手机能不能用？**
答：能。电脑和手机连同一个 WiFi，手机浏览器输入电脑的局域网 IP（把 `127.0.0.1` 换成电脑 IP）即可打开做题页。V1.0 的出卷功能在电脑上看最好。

**问：孩子的作业会不会被传到网上？**
答：不会。所有处理都在你自己电脑内存里做，程序不请求任何外部网址，任务数据重启即清空。代码是开源的，任何人都能检查这一点。

**问：要钱吗？有广告吗？**
答：免费，无广告，无收费功能。开源协议是 MIT（随便用随便改）。
