# 磐卷 · 安装说明（给不太懂电脑的家长）

**你要做的事：解压 → 双击 `start.bat` → 浏览器自动打开 → 把老师发的作业拖进去。**
全程在你自己电脑上完成，不联网上传任何东西（除了第一次装依赖要下载），孩子的作业不会离开你的电脑。

> `start.bat` 会把该做的事都做完：找 Python、首次自动装依赖、后台启动服务、
> 等服务真的就绪再打开浏览器。再双击一次不会重复启动，只会直接打开页面。
> 不想用了就双击 `stop.bat`。

---

## 第一步：确认电脑上有 Python（只需做一次）

Python 是一个免费的小工具，很多软件都靠它跑。

1. 按键盘上的 **Win + R**，弹出小窗口
2. 输入 `py -3.11 --version` 后回车
3. 看到 `Python 3.11.xx` 之类的字 → **你有，直接跳到第二步**
4. 如果提示"找不到"或窗口一闪而过 → 你需要装一个：
   - 打开 https://www.python.org/downloads/
   - 点黄色大按钮 Download 下载
   - **安装第一个界面，务必勾选最下面的 `Add python.exe to PATH`**（不勾后面会很麻烦）
   - 一路"下一步"装完即可

> 装 Python 是这类开源工具唯一的门槛。装一次，以后所有同类工具都能用。

---

## 第二步：双击 start.bat

1. 把发行包 zip **解压到一个文件夹**（右键 → 全部提取）
   ⚠️ 一定要解压，不要在压缩包里直接双击运行
2. 打开解压出来的文件夹，**双击 `start.bat`**
3. 第一次会弹出一个窗口开始自动装东西，**耐心等 1–3 分钟别关窗口**
   - 中间会滚很多字，是正常的
   - 看到 `磐卷已就绪 → http://127.0.0.1:8000/` 就说明成功了
   - 浏览器会自动打开页面

> 如果右键没有"使用 PowerShell 运行"这个选项：
> 在那个文件夹的地址栏输入 `powershell` 回车，在弹出的窗口里输入
> `.\scripts\setup.ps1` 回车即可（和双击 start.bat 效果一样）。

---

## 第三步：四步走完一张卷子

**1 上传** — 浏览器打开后看到"把老师发的作业拖进来"的大框：

- 把手机里的作业文件**拖进去**（或点「＋ 选择文件」挑）
- 支持：PDF、照片（jpg/png）、Word 文档（.docx）
- 可以一次拖好几个，**你放的顺序就是卷子的页序**；拖错了用列表里的 ↑ ↓ 调，✗ 删
- 点**「开始出卷」**，几秒后自动跳到第 2 步

**2 校对题目** — 识别出来的题一道一张卡，在这儿改完：

- **改**：题干、题型、分值、选项都能改；**增**：在某题后面补一道；**删**：删掉识别错的
- 题目里的**配图**（图形、数轴、表格）会被自动裁出来挂在题下面，不想要可以「移除」
- 改完点**「发布这张卷子」**——发布代表校对完成，之后做题页才进得去
- 不想让孩子在屏幕上做，发布后直接点**「跳过做题，去打印 →」**

**3 在线做题**（可以整个跳过）— 孩子在屏幕上做：选择点、填空打字、问答写过程。

- 中途关掉页面不丢：草稿存在本机，回来自动填回
- 想自动批改，就先由家长"自己做一遍 → 点「另存为标准答案」"，孩子再做同一张就自动判分
- 做完点**「打印：带我的答案 →」**或**「打印：带批改结果 →」**进第 4 步

**4 打印成 PDF** — 左边就是最终 PDF 的真实样子：

- 上面三个单选决定纸上有什么：**空白卷 / 我的答案 / 我的答案 + 自动批改**
  （不能选的那两项会写明为什么，比如"这份卷子还没人作答过"）
- 右边调版式：**A3 横版对开**（标准试卷样式，对折就是 A4 本子）／A4 单页／A4 两页一纸，
  还有字号、行距、边距、省墨、班级姓名栏
- **改任何一项，等半秒预览自己就重排了**，不用点按钮
- 点**「下载这份 PDF」**存文件，或**「在浏览器里打开并打印」**直接进打印对话框

## 以后怎么用

每次用只需要：**双击 `start.bat`**（它检测到服务已在跑就只开浏览器，秒级），
或者在解压文件夹的地址栏输 `powershell` 回车，再输
`.\.venv\Scripts\python -m uvicorn app.main:app --port 8000` 回车。

浏览器地址是 `http://127.0.0.1:8000/`，书签存一下更方便。

### 忘了启动服务？页面上点一下就行

如果你**双击的是 `web\index.html`**（或者书签存成了这个本地文件），页面顶部会告诉你现在是什么状态：

* 服务**在跑** → 顶部一条绿字，自动把你带到正式地址 `http://127.0.0.1:8000/`。
* 服务**没跑** → 顶部一条橙字 + 一个「▶ 启动服务」按钮，点一下服务就起来，起来后自动进页面。

要点说明白：网页自己是**不能**启动本地程序的（浏览器安全规则，谁都一样），
所以这个按钮走的是 Windows 的自定义协议 `panjuan://`：
你第一次双击 `start.bat` 时，它会顺手把这个协议注册到你自己的账户里
（写在 `HKCU\Software\Classes\panjuan`，不要管理员权限，也不影响别的软件）。
之后网页点一下 = 让 Windows 去执行我们注册好的那条隐藏启动命令。

第一次点按钮时浏览器会弹一个确认框（"要打开 磐卷 PaperForge 吗？"），
**勾上「总是允许」再点「打开」**，以后就不再问了。要是没看到这个框、按钮点了没反应，
说明这台机器还没注册过协议 —— 回去双击一次 `start.bat` 就好。

想更省事，可以让服务随开机自动启动，连按钮都不用点：

```powershell
.\scripts\install_startup.ps1 -AutoStart    # 登录 Windows 就自动起服务
.\scripts\install_startup.ps1 -Check        # 看现在注册了没、指向哪个文件夹
.\scripts\install_startup.ps1 -Remove       # 全部撤销（协议 + 开机启动）
```

> 项目文件夹**挪了位置**也不用管：下次双击 `start.bat` 会自动把协议指向新位置。
> 但如果你挪完从没双击过 start.bat，就直接点页面上的「手动方式」那条路走。

## 常见问题

**问：我双击 `web\index.html` 打开，点了「启动服务」半天没反应？**
答：先看浏览器有没有弹"要打开 磐卷 PaperForge 吗"的确认框（有时在窗口最前面，有时被挡住）。
没弹框＝这台机器还没注册过协议，回去双击一次 `start.bat`。注册状态可以用
`.\scripts\install_startup.ps1 -Check` 查。

**问：拖进去的文件里老师给的 .doc（老版 Word）打不开？**
答：用 Word 打开它，"另存为"选 `.docx`，再拖进来。老格式技术上不支持，不是漏了。

**问：蓝色窗口一闪就没了？**
答：多半是第一步的 Python 没装好或没勾 Add to PATH。重做第一步。

**问：提示"不支持的格式"？**
答：目前支持 PDF / jpg / jpeg / png / webp / bmp / docx。微信里收到的文件有时没有扩展名，重命名加上 `.jpg` 或 `.pdf` 再拖。

**问：手机能不能用？**
答：能。电脑和手机连同一个 WiFi，手机浏览器输入电脑的局域网 IP（把 `127.0.0.1` 换成电脑 IP）即可打开做题页。V1.0 的出卷功能在电脑上看最好。

**问：孩子的作业会不会被传到网上？**
答：不会。所有处理都在你自己电脑内存里做，程序不请求任何外部网址，任务数据重启即清空。代码是开源的，任何人都能检查这一点。

**问：要钱吗？有广告吗？**
答：免费，无广告，无收费功能。开源协议是 MIT（随便用随便改）。

  替代路径：让孩子**在屏幕上做题**（下一个版本会提供），从根上不需要识别手写字。
- **数学公式不做漂亮排版**，按普通文字或图片处理。
- 屏幕上作答、自动判分、导出带成绩的 PDF 回传老师 —— 这些是 V1.1，还在做。
