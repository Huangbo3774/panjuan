## 3. 口碑回路（免费传播的最大杠杆）

**机制**：家长把生成的试卷 PDF 发进群/发给老师 → 每个 PDF 都是一次曝光。

**已实现**：PDF 页脚默认带一行 `磐远试卷打印助手 · 开源免费`，且**用户可关**（预览页"页脚留出处署名"复选框，验收 F11 保证开关有效且不会连带弄掉页码）。

刻意的设计取舍：
- **不放 URL**。打印出来没人手输网址，反而像广告；项目名足够独特，搜"磐远"或"panjuan"就能找到。
- **默认开但可关**。关不掉的署名是广告，会砸掉"无广告"的承诺；可关的署名是出处，用户通常会留着。
- 灰色 9pt，右下角，不占答题区。

**可以再进一步（未做，等你定）**：
- 在导出的 PDF 元数据里写 `Creator=磐远试卷打印助手`（现在写的是 Title/Author），零视觉成本，转发时仍可溯源。
- 生成一张"给老师看的"说明页作为可选附页——把工具变成"家长给老师的交付物"，转化路径更短。

## 4. Release 正文模板（可直接粘）

```markdown
## V1.0 打印引擎

任意 PDF / 图片 / Word → 一张标准 A4 试卷 PDF。

**它解决的事**：老师深夜发来三张糊照片，打印店关门，家里没墨。
1–2 秒出一张干净 A4，不用去打印店。

**下载即用**：解压 → 双击 `start.bat` → 自动装依赖并启动 → 浏览器自动打开。
需要 Python 3.11+（脚本会自动找）。详细图文见 docs/安装说明.md。

- 自动清洗：去灰底、纠偏、裁边（按清晰度决定要不要洗，不对清晰图乱动手）
- 混合格式一次拖入，顺序即页序
- 省墨模式、字号缩放、2 合 1 省纸
- 全程本机，零外部请求，无账号无埋点，MIT 永久免费

**已知不做**：.doc 老格式、手写作业识别、数学公式排版。

验收：11 条自动化用例全过（含 100 页压力、损坏文件、混合格式合并）。
```

## 5. ⚠️ 上线前必须你拍板的一件事

`docs/P0-真实样本.md`、`docs/P0-结论.md`、`docs/M1-进度与实测.md` 里有真实材料的**文件名和 OCR 内容摘录**（例如"5·3天天练小学语文二年级上册"、具体题目文字、真实准确率数字）。

- 不含姓名、校名，但**同班家长可能认出"这就是我们用的那本"**。
- 这些内容对工程师价值很高（记录了哪些假设被实测证伪），删掉可惜。

三个选项，我按你说的执行：
1. **保留**（默认，什么都不用做）
2. **脱敏保留**：把具体书名/题目换成"某二年级语文卷"，数字保留 —— 我可以现在就做
3. **移出仓库**：把 docs 里含真实样本细节的部分挪到不入库的本地笔记，仓库只留通用结论

我推荐 2：既保住工程价值，又不暴露可识别信息。
