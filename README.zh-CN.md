# 磐卷 PaperForge

**[中文](README.zh-CN.md)** · [English](README.md)

> **老师发什么，磐卷印什么——一张干净 A4。**
> Any document. One clean A4.

把老师发来的 PDF / 图片 / Word 作业，一键变成一张**标准 A4 试卷 PDF**：能直接打印，也能在线做、自动批改、导出带成绩的 PDF 回传老师。

**省纸 · 省墨 · 省腿 · 省心**（省腿 = 不用跑打印店）

---

## 为什么做这个项目

**场景 1：周六晚 10 点。** 班主任在家长群发了三张数学卷子照片：*"明天上午 9 点要用。"* 打印店早关门了，家里的打印机上个月墨盒就干了。你对着手机里歪歪扭扭的照片，不知道该怎么办。

**场景 2：周日早上 9 点。** 打印店门口排了 7 个家长，人手一份同样的卷子照片。队伍里有人叹气：*"这老师就不能早一天发吗？"*

**场景 3：周二晚上 8 点。** 老师发了一个 PDF、两张图、一段 Word 说明。你要把它们拼成一份能打印的卷子：图片要裁边、PDF 要调字号、还要琢磨怎么不浪费纸。半小时过去了，卷子还没出来。

**孩子的作业不缺题，缺的是一张干净、标准、随时能打印的 A4 纸。**

![手机拍的作业照片 → 磐卷输出的标准 A4](docs/img/compare-photo-to-a4.png)

## Before / After

| 之前 | 之后 |
|---|---|
| 周末/深夜打印店关门，没地方打印 | 1–2 秒出一张标准 A4 试卷 PDF，24 小时随时出 |
| 图片模糊、灰底、看不清 | 自动清洗：去灰底、纠偏、裁边、增强 |
| PDF + 图片 + Word 三个格式自己拼 | 多文件混合拖进来，合并成一份，零排版操作 |
| 一年打印费几百块 | 黑白省墨、字号可调、2 合 1 省纸，工具开源免费 |
| 做完要拍照交作业，老师看不清 | （V1.1）在线做 → 自动判分 → 导出带成绩 PDF |

## 四步流程

| 步 | 做什么 | 说明 |
|---|---|---|
| **1 上传** | 把老师发的 PDF / 照片 / Word 拖进来 | 格式混着来也行，顺序就是页序；清洗、矫正、重排都在本机 |
| **2 校对题目** | 改 / 增 / 删，最后点「发布」 | 识别结果不可能全对，改题是**上传的人**的活；发布才算校对完成 |
| **3 在线做题** | 孩子在屏幕上做：选择点、填空打字、问答写过程 | **这一步可以整个跳过**，直接去第 4 步打空白卷；草稿存本机 |
| **4 打印成 PDF** | 选内容 + 调版式 → 下载或直接打印 | 见下表三种内容 |

### 第 4 步打印出来的三种东西

| 内容 | 什么时候能选 | 纸上是什么 |
|---|---|---|
| **空白卷** | 校对完（甚至没发布）就能打 | 干净题目 + 答题空位，没做任何题就是这张 |
| **我的答案** | 第 3 步提交过 | 孩子的作答原样落在纸上，不判对错 |
| **我的答案 + 自动批改** | 提交过 **且** 录了标准答案 | 加 ✓/✗/△（矢量画的，黑白打印可辨）与表头得分，直接发老师 |

不能选的那两项**照样显示，并把原因写在里面**（"这份卷子还没人作答过：先去第 3 步做题"）——
灰掉一个没有解释的按钮，用户只会反复点它或者以为程序坏了。

**版式随改随看**：A3 横版对开（两张 A4 1:1 左右拼、带密封线与装订缝，对折就是 A4 本子）
／ A4 单页 ／ A4 两页一纸（√2 缩印省纸），加上字号、行距、边距、省墨、署名。
改任何一项，450 毫秒后左侧预览自己重排一次——预览图的文件名带内容哈希，
所以"我明明切了，左边怎么没变"这种结构性缓存问题不会再出现。

## 快速开始

### 最省事：免安装版（不用装 Python）

去 [Releases](../../releases) 下载 **`磐卷-Windows-免安装.zip`**，**解压**（别在压缩包里直接双击），
双击里面的 `PaperForge.exe` —— 浏览器自动打开 `http://127.0.0.1:8000/`，就能拖文件出卷子了。
Python 和全部依赖（含 OCR 模型）都在包里，**不联网、不上传、无账号**，隐私口径与下面完全一致。
那个黑色窗口就是服务本身，关掉它 = 停止；试卷存在同目录的 `data\` 里，换电脑拷走整个文件夹即可。
第一次运行 Windows 可能弹「已保护你的电脑」，点「更多信息 → 仍要运行」（我们没买代码签名证书）。
构建与验证方式见 **[docs/打包与发布.md](docs/打包与发布.md)**。

### 想跑源码 / 参与开发

**Windows：双击项目根目录的 `start.bat`。** 它会自动找 Python 3.11+、（首次）建虚拟环境装依赖、
后台把本机服务拉起来、等健康检查真的通过再打开浏览器。再双击一次不会重复起进程，
只会直接打开页面；想关掉服务就双击 `stop.bat`。

```powershell
# 想在终端里看日志 / 换端口
.\scripts\start.ps1            # 首次启动约 10 秒
.\scripts\start.ps1 -Port 8000 -NoBrowser
.\scripts\start.ps1 -Status    # 只查在不在跑（RUNNING / STOPPED）
.\scripts\stop.ps1             # 停
```

第一次装（要下载依赖，1–3 分钟）也可以直接跑安装脚本：

```powershell
.\scripts\setup.ps1
```

非 Windows：

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
# 浏览器打开 http://127.0.0.1:8000/
```

⚠️ **必须用 Python 3.11+**。Windows 上默认 `python` 常常是旧版本（开发机上是 3.6.8，装不了本项目任何依赖），`start.ps1` / `setup.ps1` 都会显式挑 3.11+ 而不是依赖 PATH 顺序。

### 忘了启动服务怎么办：网页上点一下就行

双击 `web/index.html` 打开也能用，但要看本机服务在不在跑：

* **服务在跑** → 页面顶部出现绿条，自动把你切到正式地址 `http://127.0.0.1:8000/`（静态打开的方式功能不全，不该留在那儿）。
* **服务没跑** → 顶部出现橙条 + 「▶ 启动服务」按钮，点一下服务就起来，起来之后自动进页面。

这里有个绕不过去的物理限制：**浏览器不允许网页自己启动本地程序**（安全沙箱，任何网站都做不到）。
所以那个按钮走的是 Windows 自定义协议 `panjuan://` —— 双击一次 `start.bat` 时会自动注册
（写在你自己账户的 `HKCU\Software\Classes\panjuan`，不需要管理员权限），
之后网页点一下 = 让系统去跑我们注册好的那条隐藏启动命令。
第一次点浏览器会弹一次确认框，勾「总是允许」后就不再问。

```powershell
.\scripts\install_startup.ps1            # 只看/只做注册这件事（start.bat 已经顺带做了）
.\scripts\install_startup.ps1 -Check     # 查注册没有、指向哪个目录
.\scripts\install_startup.ps1 -AutoStart # 再进一步：登录 Windows 就自动起服务，连按钮都不用点
.\scripts\install_startup.ps1 -Remove    # 全部撤销（协议 + 开机启动项）
```

不想用开机自启的话，把 `start.bat` 右键发到桌面/任务栏，一天也就点一次。

### 发给不太懂电脑的家长

不用讲命令行——把发行包 zip 发过去，让对方**解压后双击 `start.bat`**，浏览器会自动打开。
详细步骤（含"现在还不能做什么"）写在 **[docs/安装说明.md](docs/安装说明.md)**。

### 推到自己的 GitHub

仓库已经是干净的 git 仓库（只含可分发内容，真实作业已被 `.gitignore` 排除）。
在 github.com 建一个空仓库后：

```bash
git remote add origin https://github.com/<你的用户名>/panjuan.git

```


|---|---|

## 设计原则

1. **10 秒出卷**——任何文档进来，一张标准 A4 出去，零排版操作
2. **24 小时可用**——凌晨 3 点老师发卷也能打
3. **看得清**——按**清晰度**而非像素数决定要不要清洗（实测屏摄图清晰度是手机拍照的 52 倍，对它做"增强"反而是伤害）
4. **省墨省纸**——黑白优先、省墨模式、字号缩放、2 合 1 页面
5. **不收集、不收费、无广告**——本地优先，开源可审计
6. **永远免费**

## 已知边界（不是"以后会好"，是当前不做）

- **`.doc`（2003 及更早）不支持**，请另存为 `.docx`
- **不识别孩子手写的答案**。"拍一下做完的卷子自动批改"这类功能，全世界做得好的都是收费商业服务，本项目不做。
  替代路径：让孩子**在屏幕上作答**（V1.1），从根上不需要识别手写字。
- **数学公式不做可视化排版**，按普通文字或图片处理。
- **题目配图会被自动裁下来挂在题上**（"看图列式""平面图标方向"这类），
  但裁的是"文字之外的墨"，所以图里若混着大段印刷文字，可能被一起裁进图里；
  校对页可以一键移除。
- **在线作答依赖 OCR**：扫描件里"题干全在图/表格里"的题目，只能切出题号、题干为空，
  会标成"需校对"（真实卷实测 122 题里 2 条这种碎片）。打印链路不受影响——模式 A 用的是图本身。
- **问答题不自动判分**（PRD 定的），只给关键词重合提示，最终判断留给人工。

## 技术栈

FastAPI + uvicorn · PyMuPDF（PDF 解析）· Pillow + OpenCV（图像清洗）· ReportLab（A4 出卷，嵌入系统中文字体子集）· RapidOCR（V1.1 题型识别，Apache-2.0，模型随包本地跑）· SQLite（V1.1 试卷/题目/答案/作答）· 原生 HTML/CSS/JS（零构建、全本地）

## 给想改代码的人

先读 `docs/`。里面记的不是设计愿景，是**被实测证伪的假设**——比如为什么分栏检测必须作用在原始碎片框上（先合并行会让双栏卷的间隙消失而必然漏检）、为什么清洗要按清晰度分档而不是按分辨率、为什么大题判据必须是序号递增而不是关键词表、为什么批改"不敢判错"和"乱判错"同样是失败。跳过这些，你会重新踩一遍，每次一天。

一键自检：`scripts/check.bat`（Windows，15 步）。其中三步是**检查检查器**的：
`tests/break_extractor.py` / `break_grading.py` / `break_webgate.py` 会把已修过的缺陷
逐条塞回源码（切题规则、批改判据、前端门闸与脚本编码），要求对应测试必须变红——
全绿不等于有尺，本项目已经四次被"假绿的尺"骗过（最近一次：给四个页面注入 gate.js 时
漏写注释结尾 `-->`，注释把 `<script>` 连同 `<body>` 一起吞了，页面空掉，当时所有闸门一路绿灯）。

## 目录

```
app/
 ├─ main.py        FastAPI 入口 + 17 条 API
 ├─ parsers/       pdf / docx / image → 统一中间结构
 ├─ cleaners/      8 步清洗管线 + 按清晰度自动分档
 ├─ layout/        分栏归位 + A4 块级流式排版 + 选项
 ├─ papers/        ReportLab 出卷（模式 A）+ 作答/批改导出（模式 B/C）
 ├─ extractor/     题型识别：OCR 路由 + 文本行归位 + 切题规则
 ├─ grading/       归一化 + 批改引擎（选择/判断精确，填空容错，问答待确认）
 ├─ storage/       SQLite（试卷/题目/标准答案/作答）
 └─ api/           任务表 + 流水线 + /api/papers 路由
web/               上传 / 校对 / 做题 / 打印 四页（原生 HTML/JS，零构建）
                    ├─ js/gate.js  服务门闸（没起服务时给「启动服务」按钮）
                    └─ js/app.js   步骤条顺序的唯一来源（上传→校对→做题→打印）
tests/             单测 + 变异闸门（故意打坏看测试会不会红）+ 真实材料体检 + 验收 F01–F18
docs/              可行性实测记录 + V1.1 实测 + 人话安装说明
start.bat / stop.bat   双击启动与停止（自动拉起本机服务并开浏览器）
scripts/           setup.ps1 一键安装 · start.ps1/stop.ps1 · install_startup.ps1（注册 panjuan://，
                   网页上那个「启动服务」按钮靠它）· start_hidden.vbs · check.bat 一键自检 ·
                   build_exe.ps1 一键打免安装包
packaging/         免安装包：entry.py（exe 入口）· paperforge.spec（onedir，含 OCR 模型）· env_check.py
```
